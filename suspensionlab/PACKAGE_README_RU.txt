Подвеска.Про — пробная сборка для ознакомления

Это экспериментальная версия, не проверенный инженерный калькулятор. Не используйте результаты для проектирования или эксплуатации реального автомобиля.

1. Полностью распакуйте архив в отдельную папку. Не запускайте программу прямо из ZIP.
2. Откройте папку SuspensionLab и запустите SuspensionLab.exe. Все файлы внутри папки нужны для работы; один exe отдельно не переносите.
3. Для знакомства откройте шаблон «Кольцо» и выберите «Расчёт → Ход колеса · двухрычажная…». После «Рассчитать» справа доступны «Положение», «График», «Сводка точек» и «Разбор точки». График и таблицу можно сохранить в отдельные CSV.
4. Чтобы попробовать проверку статики, включите пружину и амортизатор, задайте для учебного примера длину пружины в статике 320 мм, длину смыкания 115 мм и длины амортизатора 205 и 325 мм. Нажмите «Проверить статику»: вкладка «Статика» покажет несжатую пружину и конфликт отбоя. Это специально подобранный пример, не параметры реального автомобиля. При желании сохраните проверку в отдельный CSV.
5. Кнопка «Перенести длины из проекта…» заменяет обе длины амортизатора только после подтверждения. Значения шаблона учебные; перенос не подтверждает их пригодность. Кнопка «Из силы и скорости…» помогает получить условный линейный коэффициент из заданных силы и скорости штока, но не восстанавливает полную характеристику амортизатора.
6. Для графиков стабилизатора выберите «Расчёт → Стабилизатор и стойки · двухрычажная…», задайте учебные X = -250 мм, Z = 320 мм и жёсткость 1000 Н·м/рад. На вкладке «График» можно сравнить обе стороны. Это только условная модель.
7. Перед запуском новой версии закройте старую: обе используют общий файл автосохранения. Сохраняйте копии проектов отдельно и не пересохраняйте новый проект в старой версии без резервной копии.

Для запуска Python устанавливать не нужно. Сборка не подписана цифровым сертификатом: Windows может показать предупреждение. Проверка в GitHub Actions выполнена автоматически в offscreen-режиме; ручная проверка на чистой машине и инженерная валидация не выполнены. Программа и сборка предоставляются для тестирования, не являются окончательным релизом.

Проекты сохраняйте отдельно от папки программы и делайте резервные копии. Настройки, журнал и общий файл автосохранения хранятся в %APPDATA%\SuspensionLab. Удаление папки программы не удаляет эти данные.

Если обнаружится проблема, посмотрите «Справка → Открыть журнал» или файл %APPDATA%\SuspensionLab\logs\suspensionlab.log. Перед отправкой проверьте журнал: он может содержать имена и пути проектов. Если программа вообще не запустилась, журнала может не быть; тогда пригодится скриншот ошибки. Журнал автоматически никуда не отправляется и не описывает все действия и расчёты.
