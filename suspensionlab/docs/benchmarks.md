# Замер кинематического свипа

Запуск из каталога `suspensionlab` после установки зависимостей:

```bash
python -m scripts.benchmark_sweep --warmup 2 --repeat 7
```

Скрипт печатает JSON с отдельными временами, минимумом, медианой, максимумом, версиями Python/NumPy/SciPy, платформой и переменными окружения, влияющими на число потоков. Он **не устанавливает и не проверяет порог производительности**. Для сравнения запусков нужны одинаковые входы, версии библиотек, машина и условия нагрузки; разные сборки BLAS и число потоков могут заметно изменить результат.

Методика: учебный шаблон `ring`, передняя ось, левая сторона; ходы от −30 до +30 мм включительно с шагом 1 мм (61 точка), максимальный шаг продолжения 1 мм. Измеряется один вызов `DoubleWishbone.sweep` уже созданной модели через `time.perf_counter_ns`, после прогрева. Загрузка шаблона, создание модели и сетки, метрики, проверка компонентов, Qt, прорисовка и экспорт не включены. Скрипт проверяет количество поз, но физическую правильность или надёжность результата измерением времени не подтверждает.

Пример одного запуска в sandbox (Linux x86-64, Python 3.11.2, NumPy 2.4.6, SciPy 1.16.3; модель процессора окружение не сообщило, переменные OMP/OPENBLAS/MKL/NUMEXPR не заданы): два прогрева и семь измерений **14,677; 13,600; 13,725; 13,423; 13,608; 13,744; 13,577 мс**. Медиана 13,608 мс; минимум 13,423 мс; максимум 14,677 мс. Это только пример для указанного короткого кинематического свипа, не гарантия скорости интерфейса или целевой Windows-машины и не подтверждение общей цели ≤50 мс для всех сценариев.
