# Записи, ожидающие переноса в журнал Google Drive

Google Drive был выключен для разговора; пользователь попросил продолжать без него и обновить общий журнал, когда он будет дома и скажет. Эти записи ещё **не перенесены в Drive**. Это дополнение к прежнему журналу, не его замена и не восстановленная дословная история. При переносе сохранить весь прежний текст и комментарии, в том числе записи шагов 1–5 этого цикла. Основной журнал: https://drive.google.com/file/d/1A455-pT06GnStSFQjINzjNI_uEdeLHpd/view?usp=drivesdk. Предыдущие шаги нового цикла добавлялись в комментариях; при скачивании файла комментарии могут отсутствовать.

PR: https://github.com/Foont1k-ru/prochnost-gibrid/pull/1. Демонстрационная сборка на этих шагах не выпускалась; ранее собранная версия не содержит эти изменения. Реальная модель вручную в Windows GUI на этих версиях не проверялась. Приватные CAD-файлы не включались в репозиторий или CI.

## Следующий цикл — шаг 6

Коммиты `a33417b` и `a76a1d4`. Ручное сохранение проекта блокирует общую копию автосохранения и обнаруженные символические/жёсткие ссылки на неё, даже после разрешения автоматической перезаписи или обычного открытия копии; сохранение в другой файл доступно. Неудачная проверка пути останавливает запись. Определение пути автосохранения больше не создаёт каталог. Это не блокировка доступа внешних программ, не защита от всех гонок и не замена резервным копиям.

Локально: 56 профильных headless-тестов, Ruff, mypy, pip check и diff check. Qt локально не запускался из-за отсутствующей libGL. CI на `a33417b`: Windows прошёл, Linux-тест восстановления завершился ошибкой в прогоне https://github.com/Foont1k-ru/prochnost-gibrid/actions/runs/44015945018. Отдельно локально воспроизведено ложное обнаружение изменения файла из-за обновления времени доступа при чтении; в `a76a1d4` сравнение больше не включает время доступа, добавлен тест. Повторные Linux/Windows/Qt https://github.com/Foont1k-ru/prochnost-gibrid/actions/runs/44016542295 и Open CASCADE https://github.com/Foont1k-ru/prochnost-gibrid/actions/runs/44016549293 прошли.

## Следующий цикл — шаг 7

Коммиты `92dbe9a` и `6daf6d5`. Совместимые экземпляры используют неблокирующую системную блокировку при проверке и автоматической записи общей копии, включая сравнение результата после записи. При занятости показана пауза, запись будет повторена по таймеру; если другой экземпляр уже изменил содержимое, отдельно требуется решение о перезаписи. Остаётся пустой файл `autosave.susp.json.lock`; не удалять и не заменять его во время работы. ОС освобождает блокировку при завершении процесса. Старые версии и другие программы могут игнорировать блокировку, сетевые и нестандартные файловые системы и подмена sidecar могут нарушить координацию; отдельные резервные копии остаются необходимыми.

Проверены конкуренция отдельных процессов, освобождение после аварийного выхода, отказ при символической ссылке sidecar, повтор записи после занятости и защита от изменения другим экземпляром. Локально 59 профильных headless-тестов, Ruff, mypy в режимах Linux и Windows, pip check и diff check. Qt локально не запускался из-за отсутствующей libGL. Первый CI https://github.com/Foont1k-ru/prochnost-gibrid/actions/runs/44018230304: Linux и Windows Python 3.11 прошли, Windows Python 3.12 остановился на mypy из-за платформенных объявлений `fcntl`. Исправлено в `6daf6d5`; повторные Linux/Windows/Qt https://github.com/Foont1k-ru/prochnost-gibrid/actions/runs/44018670317 и Open CASCADE https://github.com/Foont1k-ru/prochnost-gibrid/actions/runs/44018674372 прошли.
