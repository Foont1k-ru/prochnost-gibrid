# Подвеска.Про — этап M0

Нативный офлайн-каркас приложения на Python 3.11+ и PySide6. Это **не готовый инженерный калькулятор**: кинематический решатель, метрики, рекомендации и чертежи ещё не реализованы. Схема показывает исходную геометрию, не результаты расчёта. Проекты и шаблоны — локальные JSON-файлы.

## Установка и запуск

Windows (PowerShell):

```powershell
cd suspensionlab
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Linux/macOS:

```bash
cd suspensionlab
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m suspensionlab
```

Установку зависимостей необходимо выполнить заранее; сама программа не выполняет сетевых запросов. Для Linux необходимы системные библиотеки Qt и графическая сессия. Визуально протестировать интерфейс следует на целевой Windows: сборка и работа на чистой системе ещё не проверены.

## Проверки

```bash
python -m pytest -q
ruff check .
mypy suspensionlab
```

На машине без экрана Qt можно запускать с `QT_QPA_PLATFORM=offscreen`, если установлены необходимые системные библиотеки. В GitHub Actions отдельный workflow «Подвеска.Про — тесты Windows» устанавливает приложение, запускает Ruff, mypy и полный pytest, включая тесты Qt в режиме offscreen; отчёт pytest сохраняется как артефакт. Это автоматические тесты, не визуальная проверка и не сборка готового exe. Windows-сборка PyInstaller предусмотрена в M7, готовой инструкции и проверенного исполняемого файла пока нет.

## Работа с проектом

Откройте шаблон, выберите точку/узел в дереве, измените значение в инспекторе, сохраните `.susp.json`. Вкладки показывают переднюю и заднюю оси и их условное совмещение. Отмена/повтор доступны через меню. Автосохранение записывает `autosave.susp.json` в каталог настроек; автоматического предложения восстановления пока нет — файл можно открыть вручную. Каталог: `%APPDATA%/SuspensionLab` на Windows, `$XDG_CONFIG_HOME/SuspensionLab` или `~/.config/SuspensionLab` на Linux.

## Инженерное ограничение

Предполагается кинематическая модель с жёсткими звеньями и идеальными шарнирами; податливость сайлентблоков, деформации и прочность не учитываются. Приложение не заменяет прочностной расчёт, натурные измерения и согласование с конструктором. До реализации и валидации следующих этапов не используйте его для инженерных решений.

Описание структуры сериализованного файла находится в `suspensionlab/resources/schema/project-1.0.schema.json`. Это базовая структурная схема, не инженерная валидация; полный прогон JSON Schema при загрузке пока не выполняется.

## Разработка ядра M1

Независимое от интерфейса ядро двухрычажной подвески находится в `suspensionlab/core/double_wishbone.py`; его ограничения и формулы описаны в `docs/formulas.md`. Этап M1 не завершён, показ схемы в окне пока не использует его результаты. Проверка только ядра, без Qt:

```bash
python -m pytest tests/test_kinematics.py -q
```

Для полного набора тестов требуется рабочая среда Qt. Из рабочего каталога `suspensionlab` можно также вызвать библиотеку напрямую:

```python
from suspensionlab.model.templates import load_template
from suspensionlab.core.double_wishbone import DoubleWishbone
from suspensionlab.core.metrics import corner_metrics

model = DoubleWishbone(load_template("ring").front)
pose = model.solve(30.0)
print(corner_metrics(model, pose))
```

Прямой вызов `corner_metrics` по умолчанию принимает нулевые статические углы; `analyze_corner` использует настройку проекта, считая стороны симметричными. Пятно контакта приближается проекцией центра колеса на землю. Не используйте эти результаты для эксплуатации или проектных решений без независимой инженерной проверки.
